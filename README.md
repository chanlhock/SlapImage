# Welcome to SlapImage Apps

This is my attempt to create a utility Android Apps which rich features and useful functions using Android Studio Meerkat with the assistance of DeepSeek.

## Development Platform
SlapImage is developed using:
- my old MacBook Air 2017 with Intel Processor.
- Android Studio Meerkat 2024 3.1 Patch 1

## Platform tested:
I have tested mostly my code on:
- my Huawei P50 Pro mobile phone running EMUI 14.2.0 (Android 12).

In addition I have also tested to some extend on:
- my son's Huawei Matepad 12 X Tablet running on Harmony OS 4.2.0.\
